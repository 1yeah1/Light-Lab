# 🔦 光的反射与折射实验室

面向小学五到六年级学生的科学教具，帮助学生直观理解光的反射和折射现象。

## 安装与启动

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 三个一级模块

应用已重组为三个一级 tab：

1. **📖 学一学**：知识卡片学习模块

3. **✏️ 练一练**：判断题和单选题练习

## 🔦 四个实验场景

### 🪞 场景 A：光的反射

**对应教材**：光的反射定律

**建议时长**：10–15 分钟

**操作**：拖动滑块改变入射角（10°–80°），观察反射光的方向变化。

**课堂提问**：
- 反射角和入射角有什么关系？
- 当入射角增大时，反射角怎么变化？
- 如果光沿着法线直射到镜面上（入射角为 0°），反射光会去哪里？

---

### 🥢 场景 B：水中的筷子

**对应教材**：光的折射现象

**建议时长**：10 分钟

**操作**：拖动滑块改变筷子插入水中的深度，观察筷子看起来的弯曲程度。

**课堂提问**：
- 筷子在水面处看起来发生了什么变化？
- 为什么筷子看起来弯了？
- 光从水里出来时，是靠近法线还是远离法线？

---

### 💧 场景 C：光进水里

**对应教材**：光从空气进入水中的折射规律

**建议时长**：15 分钟

**操作**：
- 拖动滑块改变光照射到水面的位置
- 在侧边栏切换下方介质（水 / 玻璃）

**课堂提问**：
- 光从空气进入水中时，折射角和入射角哪个大？
- 反射角和入射角有什么关系？
- 换一种介质（比如玻璃），折射角会变化吗？

---

### 🎯 场景 D：镜子打靶

**对应教材**：光的反射定律应用

**建议时长**：20–30 分钟

**操作**：
- 选择难度（1–5 面镜）
- 调整每面平面镜的角度，让激光经过多次反射后命中靶心
- 点击"💡 提示"获取调整建议

**课堂提问**：
- 每面镜子对光线方向有什么影响？
- 如何通过多次反射改变光线的路径？
- 如果增加一面镜子，需要怎样调整其他镜子的角度？

#### 难度预设与已知解

| 难度 | 镜子数 | 已知解（角度） | 反射次数 |
|------|--------|----------------|----------|
| 1 面镜（初级） | 1 | [45] | 1 |
| 2 面镜（中级） | 2 | [-45, -45] | 2 |
| 3 面镜（高级） | 3 | [-45, -45, 45] | 3 |
| 4 面镜（专家） | 4 | [-45, -45, 45, -45] | 4 |
| 5 面镜（大师） | 5 | [-45, -45, 45, -45, 45] | 5 |

## 教学目标

1. 认识法线，能指出入射角、反射角、折射角
2. 通过观察发现：**反射角 = 入射角**
3. 通过观察发现：**光从空气斜射入水中时，折射角 < 入射角**
4. 通过打靶游戏理解：**多次反射可以改变光路方向**
5. 通过知识卡片和练习巩固：**理解光现象的原理和应用**
